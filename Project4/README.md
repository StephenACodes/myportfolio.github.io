# Optimizing Regression Models with Coordinate Descent

This folder contains two files: one is an HTML file with the code, and the other is a report in PDF format. Both can be viewed by clicking on the respective files.

**Summary**: This project involved developing coordinate descent algorithms for Lasso and Elastic Net in R to improve model efficiency. A simulation framework with 50 iterations was designed to evaluate model performance under varying data conditions. The project ultimately demonstrated Elastic Net’s superiority over Lasso in terms of predictive accuracy and variable selection.

### Tools Used
- **R Programming Language** for executing R codes and creating visualisations.
