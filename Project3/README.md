# Uncovering What Makes Reviews on Yelp Popular

**Summary**: This project aimed to predict the popularity of Yelp reviews by using Natural Language Processing (NLP) and Machine Learning (ML) techniques. Using PySpark on Google Cloud Platform (GCP), large-scale Yelp review data was processed to extract key linguistic and user-based features. A popularity score was defined to quantify review relevance and ML models were trained to predict which new reviews are likely to gain traction.

The python notebook detailing the data extraction, processing and modelling can be viewed in the repository above or be accessed [here](https://github.com/StephenACodes/myportfolio.github.io/blob/main/Project3/YelpProject.ipynb)

### Tools Used
- **Python** for executing Python codes for model development.
- **Google Cloud Computing** for running the Python notebook and handling computations.

# Conclusion 

Our analysis on Yelp data has provided valuable insights into the different factors that influence the popularity of reviews on the platform and can be used to predict the reach of a review. By examining various features of the review ranging from its linguistic characteristics to the attributes of the reviewer, we have identified key predictors of review popularity. However, it is important to  note that our existing prediction models may not perform as optimally due to the limitations discussed in the project file. Even then, our work is significant in the direction to aid stakeholders better understand the user engagement on popular platforms like Yelp as well as for researchers seeking to understand user behavior on review platforms.
