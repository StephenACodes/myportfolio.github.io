# Comparing Machine Learning methods for predicting income increase

**Summary**: This project applies machine learning to predict regional economic growth in New York using social capital indicators from the American Community Survey (2014–2019). We explore two tasks: regression (predicting percentage change in median income) and classification (predicting income increase/decrease) using models like Lasso, PCR (Principal Component Regression), QDA (Quadratic Discriminant Analysis), and Random Forest on 4,784 data points. Implemented in R with API data retrieval, it evaluates performance via RMSE, accuracy, and sensitivity-specificity trade-offs, addressing class imbalance. The code, implemented in R, demonstrates data retrieval via API, preprocessing, and model evaluation, offering insights into socioeconomic prediction challenges.

The R notebook, rendered as HTML via R Markdown, outlines the code for data extraction, processing, and modeling.
