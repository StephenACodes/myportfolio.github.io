# A/B Testing in Mobile Games: Analyzing Player Retention in Cookie Cats

**Summary**: Cookie Cats, a popular match-three puzzle game by Tactile Entertainment, features gates that require waiting or in-app purchases to progress. This project uses A/B testing methods to analyze the impact of moving the first gate from level 30 to level 40 on player retention. 

The python notebook detailing the process can be viewed in the repository above or be accessed [here](https://github.com/StephenACodes/myportfolio.github.io/blob/main/Project5/Notebook.ipynb)

### Tools Used
- **Python** for executing Python codes for A/B testing.
  
# Conclusion 

The data shows that 7-day retention is higher when the gate is at level 30 rather than level 40, suggesting it should not be moved. While other metrics like gameplay and purchases offer insights, retention is key—without it, in-game spending loses significance.
